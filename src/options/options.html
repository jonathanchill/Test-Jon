Mail Lens

Flags Gmail messages as Spam, AI-written or Human, in the message list and inside the open message.

Claude API key

Create one at console.anthropic.com. Without a key the extension still works, using its built-in offline scoring — which is noticeably rougher.

The key is kept in this browser profile's extension storage. Anyone with access to this Chrome profile can read it. Use a key scoped to a workspace you can revoke.

Model

What gets checked

List rows are sent in batches of eight per API call, and only rows you actually scroll past are checked. Every verdict is cached for 30 days, so each message costs you one check.

Today

How much to trust it

Spam detection is reliable enough to act on. AI-authorship detection is not a solved problem — no detector, this one included, can prove text was machine-written. Fluent, well-organised writing by a careful human is the common false positive, and a light human edit defeats detection entirely. Read the percentage as the strength of a hunch, not a measurement, and treat a badge on someone's mail as a prompt to look closer rather than a verdict about them.

Mail Lens reads what Gmail has already drawn on screen. It sends the sender, subject and message text of the mail you look at to the Anthropic API when a Claude mode is on, and nowhere else. Turn either mode to offline scoring to stop that.
